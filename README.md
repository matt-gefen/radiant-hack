# Radiant Hack
 
Welcome to my home table TTRPG rules I've been hacking together!

This game is based on and takes mechanics from the following games

- [The Black Hack](https://the-black-hack.jehaisleprintemps.net/) by David Black
- The Electrum Archive by Emil Boven
- DURF by Emil Boven
- Cairn by Yochai Gal
- Block, Dodge, Parry by Lars Huijbregts
- Old School Essentials by Necrotic Gnome

This is for personal use at my table and not intended for commercial use as of now

This project uses the following template for ease of starting: [Nextra](https://nextra.site).
